## 실제 브라우저 점검

- React 포트폴리오 메인, 카테고리·시술 16건, 이미지, 고객 로그인 상태를 확인했다.
- 예약 화면에서 미래 날짜 변경 후 서버 계산 슬롯 15건을 확인했다.
- 카카오 계정 정보는 저장·출력하지 않았으며 인증 요청에만 사용했다.
- 노쇼 동의 체크박스는 실제 브라우저에서 `false → true` 변경을 확인했다.
- 이달의 TOP5와 네일 메뉴는 클릭 시 갤러리 1개와 이미지 3장이 표시되고 콘솔 오류가 없음을 확인했다.

## 외부 설정 조치

1. Google Cloud Console에서 새 OAuth 웹 클라이언트를 만들고 `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`을 교체한다.
2. 승인된 리디렉션 URI에 `http://127.0.0.1:8082/login/oauth2/code/google`을 등록한다.
3. Kakao Developers에서 REST API 키·Client Secret 활성 상태와 `http://127.0.0.1:8082/login/oauth2/code/kakao`를 확인한다.
4. 새 환경변수 주입 후 서버를 재시작하고 두 공급자의 콜백·세션 생성을 재검사한다.

## 잔여 경고

- Oracle 18은 현재 Hibernate가 지원하는 최소 Oracle 19보다 낮아 호환 경고가 발생한다.
- v2는 기존 `DB_*`, v3는 로컬 프로필/`ORACLE_*` 구성 방식이 달라 같은 셸에서 v2 DB 테스트 시 자격 설정을 별도로 맞춰야 한다.
- v2 재검사 결과 7건 중 DB 비연결 테스트 2건은 통과했으며, DB 연동 5건은 `ORA-01017`(기존 Oracle 자격 불일치)로 중단됐다.
