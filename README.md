## 🗂️ 버전 구성

| 버전 | 역할 | 주요 기술 |
| --- | --- | --- |
| [V1](MarinboySalon_v1/README.md) | 예약 기능의 기본 흐름 학습 | Spring MVC, JSP, MyBatis, MySQL |
| [V2](MarinboySalon_v2/README.md) | 관리자 기능과 예약 운영 확장 | Spring Boot, Spring Security, MyBatis |
| [V3](MarinboySalon_v3/README.md) | 웹 서비스와 공통 REST API | Next.js, Spring Boot, MyBatis, MySQL, Redis |
| [V4](MarinboySalon_v4/README.md) | V3 API·DB를 공유하는 앱 | Flutter, Dart, Riverpod, Dio |

> V1·V2는 학습 과정을 보존한 버전입니다. 웹 서비스는 V3를 유지하고, V4는 기존 백엔드에 연결하는 별도 앱으로 확장했습니다.

## 프로젝트 한눈에 보기

| 구분 | 내용 |
| --- | --- |
| 고객 기능 | 시술 조회, 일반·소셜 로그인, 예약 가능 시간 조회, 예약 등록·조회·취소 |
| 관리자 앱 | 예약 현황과 상태 변경, 예약 데이터 기준 예상 매출 확인 |
| 공통 구조 | V3 Next.js 웹 · V4 Flutter 앱 ↔ Spring Boot REST API ↔ MySQL·Redis |
| 외부 연동 | OAuth(Google·Kakao·Naver), Google Calendar(운영 키·권한 설정 필요) |
| 제외 범위 | 직원관리 · 직원배정 · 근무표 |
| 운영 | AWS EC2와 Nginx 기반 배포, GitHub Actions CI/CD |

V4는 V3의 모든 웹 화면을 복제하지 않습니다. 두 클라이언트가 계정·시술·예약 데이터와 서버 검증을 공유하고, 후기·시술 편집·이벤트 같은 V3 전용 화면은 웹에서 계속 제공합니다.
