# Marinboy Salon 예약·후기 분석 결과보고서

## 1. 목적

기존 포트폴리오의 완료 예약·후기 데이터를 Django 분석 화면으로 옮기고, Pandas 집계 결과를 운영자가 빠르게 파악할 수 있도록 시각화했다.

## 2. 데이터 기준

| 구분 | 내용 |
|---|---|
| 원본 근거 | `MarinboySalon_v3/database/migrations/20260909_portfolio_review_seed.sql` |
| 분석 건수 | 완료 예약 및 후기 20건 |
| 분석 기간 | 2026-08-19 ~ 2026-09-07 |
| 개인정보 처리 | 이름·이메일·전화번호를 CSV에서 제외한 익명 분석 데이터 |
| 매출 기준 | SQL의 완료 예약 가격 구조를 재현하기 위해 `두피 클리닉` 기본가 90,000원을 분석용 값으로 사용 |

> 매출은 실제 운영 매출이 아니라 수업용 포트폴리오 시드에서 재현한 분석값이다.

## 3. 구현 흐름

```text
포트폴리오 SQL 시드
        ↓ (익명 CSV 변환)
Django SQLite / PortfolioReservation
        ↓ (Pandas groupby, agg, mean)
Django View
        ↓ (json_script)
Chart.js 대시보드
```

## 4. 분석 결과

| 지표 | 결과 | 해석 |
|---|---:|---|
| 완료 예약 | 20건 | 분석 기간 동안 매일 1건의 완료 예약 데이터가 존재한다. |
| 분석용 매출 합계 | 1,800,000원 | 90,000원 × 20건으로 계산된 수업용 재현 값이다. |
| 평균 후기 평점 | 4.7점 | 5점 14건, 4점 6건으로 전반 만족도가 높다. |
| 4점 이상 비율 | 100.0% | 부정 후기 탐지보다는 4점 고객의 개선 의견을 수집하는 단계가 적합하다. |
| 최다 예약 시술 | 두피 클리닉 20건 | 현재 시드는 단일 메뉴 중심이므로, 이후 다양한 메뉴 예약 데이터를 쌓아 비교해야 한다. |

## 5. 분석 인사이트

1. 후기의 평점은 높지만 4점 후기 6건이 있어, 상담·손질 편의성 같은 문장을 분류하면 서비스 개선 포인트를 찾을 수 있다.
2. 현재 20건 모두 한 시술이므로 실제 운영에서는 시술별 예약 건수·객단가·평점 비교를 위해 메뉴별 완료 예약을 추가로 수집해야 한다.
3. 일자별 건수는 균일한 포트폴리오 시드이므로, 실제 데이터가 연결되면 요일·시간대별 예약 집중도를 추가 분석하는 것이 다음 단계다.
